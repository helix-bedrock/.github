# Security policy

## Reporting a vulnerability

**Do not open a public issue.** Report it privately with GitHub's
"Report a vulnerability" button on the affected repo's **Security** tab
(private vulnerability reporting is enabled on every repo).

Include what is affected, how to reproduce it, and the impact. Examples: a
packet that crashes the server, a way to bypass permissions, or a plugin
sandbox escape.

We aim to reply within 7 days and to fix confirmed issues before disclosing
them publicly. We credit reporters unless they ask us not to.

## Supported versions

Until Helix reaches 1.0, only the latest release and `main` get security fixes.
