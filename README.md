# helix-bedrock/.github

Organization-wide files for [Helix](https://github.com/helix-bedrock).

- `profile/README.md` is the public organization profile page.
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, the PR template and
  the issue templates apply automatically to every repo that does not have its
  own.
- The project rules live here:

| File | Covers |
|---|---|
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Workflow, reviews, DCO, licensing |
| [`AI_POLICY.md`](AI_POLICY.md) | Using AI tools on Helix |
| [`AGENT_RULES.md`](AGENT_RULES.md) | Rules AI coding agents follow in every repo |
| [`REPOS.md`](REPOS.md) | Creating, naming, configuring and releasing repos |
| [`LIBRARIES.md`](LIBRARIES.md) | Extra rules for standalone libraries |
| [`PORTING.md`](PORTING.md) | Translating code from other projects |
| [`SETUP.md`](SETUP.md) | Developer setup and one-time org setup |
| [`TESTING.md`](TESTING.md) | Go tests, required in-game testing, load testing |
| [`API_DESIGN.md`](API_DESIGN.md) | Status of the engine and plugin API design |
| [`GOVERNANCE.md`](GOVERNANCE.md) | Roles and how decisions are made |
| [`MAINTAINERS.md`](MAINTAINERS.md) | Who maintains what |
| [`CONTRIBUTORS.md`](CONTRIBUTORS.md) | Everyone who has helped, and how |
