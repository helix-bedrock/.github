# Code of conduct

Helix follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Read it there; this page sums it up and says how we enforce it.

## In short

- Be respectful and welcoming. Disagree about code, not about people.
- No harassment, insults, discrimination, sexual content or personal attacks.
- No publishing other people's private information.
- Assume good faith, and accept that maintainers make the final call.

This applies in every `helix-bedrock` space: repos, issues, PRs, Discussions,
Discord and events where you represent the project.

## Reporting

Report problems privately by direct message to any core maintainer listed in
[`MAINTAINERS.md`](MAINTAINERS.md). Reports are kept confidential.

## Enforcement

Maintainers may, depending on severity:

1. Send a private warning.
2. Hide or delete comments and lock threads.
3. Temporarily block someone from the organization.
4. Permanently ban someone from the organization.
