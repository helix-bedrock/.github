# Contributors

Everyone who has helped build Helix, and what they helped with. Code, testing,
design, docs, art, translations, bug reports and support all count.

Maintainers add an entry (or update an existing one) when they merge
someone's first PR, and update it when someone helps in a new area. You can
also open a PR adding yourself for help that was not a code change.
